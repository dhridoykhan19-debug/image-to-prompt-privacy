Privacy Policy

Image to Prompt

Effective date: October 13, 2026

This Privacy Policy explains how the Image to Prompt browser extension by Ridoy Tech (“the Extension”) handles information when you use it to generate AI prompts from images you choose on websites.

1. Information the Extension handles

  • Gemini API keys: API keys that you enter are saved in Chrome's local extension storage (chrome.storage.local) on your browser so the Extension can make requests to Google Gemini. The Extension also stores settings such as prompt style, model preferences, usage counts, and key/model status.
  • Images you choose: When you request a prompt, the Extension retrieves the selected image and sends image data to the Google Gemini API to analyze it and generate a prompt.
  • Generated prompts: The prompt returned by Gemini is displayed so you can copy it. If you use the batch feature, generated prompts are combined into a TXT file and saved to your Downloads folder at your request.

2. How information is used

The Extension uses this information only to provide its image-to-prompt features, manage your settings and API keys, select an available Gemini model, handle API limits, and create prompt text files when requested.

3. Google Gemini and third-party processing

When you generate a prompt, the selected image and your Gemini API key are sent in requests to Google's Gemini API. Google processes these requests under its own applicable terms and privacy practices. Review Google's information at Gemini API Terms and Google Privacy Policy.

The Extension may also request the selected image from its source website. Access to an image can depend on the website's technical restrictions and permissions.

4. Storage and security

API keys and Extension settings are stored in Chrome local extension storage on your device. The Extension does not provide its own account system or a separate developer-operated server for storing your keys. However, a key is transmitted to Google when it is used to call the Gemini API. Do not enter API keys that you are not authorized to use, and protect access to your browser profile.

You can remove saved API keys through the Extension's API Keys screen. Uninstalling the Extension or clearing its stored data may also remove locally stored settings.

5. Data sharing and sale

Ridoy Tech does not sell personal information. Information is sent to Google only as needed to fulfill your request to generate prompts and to use the Gemini API. The Extension does not use the information it handles for advertising, creditworthiness, or lending decisions.

6. Browsing activity

The Extension can display image controls on websites so you can choose an image. It does not need to collect or maintain a browsing-history log to provide its core feature. The broad site access requested by the Extension is intended to support image selection across websites; image data is processed when you invoke the image-to-prompt feature.

7. Children's privacy

The Extension is a general-purpose productivity tool and is not designed to collect personal information from children.

8. Changes to this policy

This policy may be updated if the Extension's features or data practices change. The latest version should be published at the same URL, with the effective date updated when appropriate.

9. Contact

For privacy questions or requests related to this Extension, contact the developer through the support contact or support URL provided on the Image to Prompt Chrome Web Store listing.
